# RR Character Manager

A GUI tool for managing custom characters in Retro Rewind.

<img width="1917" height="1017" alt="image" src="https://github.com/user-attachments/assets/8aa9322e-7840-4e0a-a115-78eda8015ed5" />

*Note: This project was developed with supplemental AI assistance.*

## Features

- **Character Management:** View all installed custom characters in an organized interface, including CSS and minimap icons.

- **Character Customization:** Easily edit character names, authors, icons, and slot assignments.

- **Slot Organization:** Rearrange characters by dragging and dropping, entering a specific slot number, or shifting slots by an X amount.

- **Character Importing:** Import custom characters to automatically detect  BRRES models and character icons. Detection might not always identify the correct model or every icon.

- **Custom .mkchara Format:** Export characters into `.mkchara` packages containing their models, icons, names, authors, and other character information. Importing these packages keeps all of this information. Useful for character creators as well, as you can now upload this to your mod pages.
- **Batch Import and Export:** Import or export multiple `.mkchara` packages at once.

- **Patches Mode:** Can not edit existing characters, but easy add new characters as patches

- **Developer Mode:** Can edit built in characters, from changing their names and icons, to moving their slots. Useful for developers when using RR character code

- **Character Sound Editing:** Easily edit and add sounds to a custom character, by replacing audio with .wav files. 

- **Warn about overlap:** When an RR update comes out, and a built in character overlaps with a patched character and warns you about it.
