# RR Character Manager — 1.0

Manage custom Mario Kart Wii characters for Retro Rewind and compatible pulsar engine mods that use RR custom characters. Import and export `.mkchara` packages, edit names and icons, organize slots, and edit character voices.

## Run from source

Requires Python 3.10 or newer. Windows, macOS, and Linux use the same application and resource formats.

1. Run **Install Dependencies.bat**.
2. Run **Run Retro Rewind Character Manager.bat**.
3. Choose your `Character` folder, `Assets/ReplacedAssets.szs`, and `Patches` folder.

On macOS or Linux, create a virtual environment, install `requirements.txt`, then run `python main.py`.

## Updates

The app checks https://github.com/bsl3/RR-Character-Manager at startup. A newer stable version shows **Download** and **Later**. **Help → Check for Updates** checks manually. Downloads open in your browser; nothing is installed automatically. The repository cannot be changed in the app.

Tags `v1.0` and `v1.0.0` refer to the same version. Draft and prerelease versions are ignored. Downloads match your operating system and architecture; otherwise the official release page opens.
